## 🇲🇦 Darija: Kifach tkhdem l-mecherou3 f l-PC dyalk bla machakil

Ila knti katzil l-mecherou3 l-PC dyalk w mazaal katichouf l-pijama store l-qdima, tbe3 had l-khotowat b l-khosos bach tm7i l-khba2 (cache) w tkhdem b taghyirat l-jdida dyal **GIRL STORE**:

1. **M7i l-fichiers l-qdamin**: msa7 l-dosser dyal l-mecherou3 l-qdim li 3ndek f l-PC bach maykounch tadakhoul.
2. **Decompresser l-ZIP l-jdid**: khwi l-fichiyat dyal l-ZIP l-jdid f dosser jdid.
3. **Installer l-packages**: hell terminal f dak l-folder jdid w ktab:
   ```bash
   npm install
   ```
4. **Khdem mode Development (Live compilation)**:
   hadi hia l-ay2a l-mose7a bach tchouf l-taghyirat direct, ktbi:
   ```bash
   npm run dev
   ```
   apres hell l-navigateur dyalk l hna: `http://localhost:3000`

5. **Ila bghiti t-builder l-mecherou3 l-production**:
   ```bash
   npm run build
   npm start
   ```

## 🇫🇷 Comment lancer le projet sur votre PC sans problème de cache

Si vous téléchargez le projet sur votre ordinateur et voyez toujours l'ancienne version :

1. **Supprimez l'ancien dossier** pour éviter tout conflit avec des fichiers mis en cache.
2. **Dézippez le nouveau fichier** importé (contenant toutes les modifications de GIRL STORE).
3. Ouvrez un terminal dans le dossier et installez les dépendances :
   ```bash
   npm install
   ```
4. Lancez le serveur de développement :
   ```bash
   npm run dev
   ```
   et ouvrez `http://localhost:3000` dans votre navigateur.
5. Pour générer un build de production tout neuf :
   ```bash
   npm run build
   npm start
   ```
